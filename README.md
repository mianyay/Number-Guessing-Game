# Number Guessing Game
A browser game where users try to guess a number within a range they can choose

## Live demo
https://mianyay.github.io/Number-Guessing-Game/

## About
 Guess a number within the range you choose and try to guess in less attempts in your previous games to get beat your highscore!

## Features
- Randomised number generation
- User can change the range
- Favicon
- Attempts + Highscore
- Pixel font
- Number guess history
- Confetti

## How to run
Download the files and open index.html in a browser.

## Built with
- CSS
- HTML
- JS
